## Distinct from MCP Suite

The playbook requires P2 to read as different from MCP Suite. MCP Suite is retrieval over a document store, in Python.
This is a typed query surface over a versioned relational release, in TypeScript, where the tests are about the
grain of the answers and the integrity of the data behind them. The card should say that in its demonstrates line,
which it does.
